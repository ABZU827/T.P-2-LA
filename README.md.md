# 🐍 Laboratorio de Aplicaciones II – Proyecto de Menú Interactivo en Python

## 📘 Descripción General
Este proyecto fue desarrollado para la materia **Laboratorio de Aplicaciones II (6° G)** y tiene como propósito practicar la creación de menús interactivos empleando Python.  
A lo largo del programa se utilizan conceptos fundamentales de la programación, tales como:

- Estructuras condicionales (`if`, `elif`, `else`)  
- Bucles (`while`, `for`)  
- Funciones para organizar mejor el código  
- Manejo de errores para evitar fallos inesperados  

El sistema presenta un menú principal que permanece activo hasta que el usuario decide finalizar la ejecución.

---

## ⚙️ Opciones del Menú

### 👋 1. Saludo Personalizado  
El programa solicita el nombre del usuario y genera un mensaje de bienvenida adaptado a la entrada.

### ➕ 2. Suma de Dos Números  
Se piden dos valores numéricos, se calcula su suma y se muestra el resultado.  
Incluye validación para evitar errores cuando se ingresan datos no válidos.

### 🔢 3. Mostrar Números del 1 al 10  
Mediante un bucle `for`, el programa imprime en pantalla los números del 1 al 10.

### 🚪 4. Salir del Programa  
Finaliza la ejecución mostrando un mensaje de despedida.

---

## 🧠 Contenidos Aprendidos

### 🔧 Funciones  
Utilizadas para dividir el programa en partes más limpias y fáciles de mantener.

### 🔄 Bucle `while`  
Permite que el menú se repita continuamente hasta que el usuario elija la opción de salir.

### 🔍 Condicionales  
Determinantes para decidir qué acción corresponde a cada opción seleccionada.

### 🛡️ Manejo de Excepciones (`try-except`)  
Evita que el programa termine abruptamente si el usuario ingresa un dato no permitido.
